# Twicaster 検出ストリーム統一リスト化およびUI操作性改善計画

## 目的
1. 「VOD / ライブ / 録画中」に分かれていたタブ分割を撤廃し、開いているツイキャスページから検出されたストリームを最新順（上に足していく形）で1つのリストに一元化して表示する。
2. 画面遷移やタブのクラス制御の不備によりタップ（クリック）操作が効かなくなっていた問題を解消する。
3. 履歴画面への切り替えやストリーム詳細への遷移を破綻なく動作させる。
4. 既に開いているタブ（TwitCasting）の自動アタッチ・検出を強化し、ポップアップを開いた際にも確実にストリームが検知・蓄積されるようにする。
