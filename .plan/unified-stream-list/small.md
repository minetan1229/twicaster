# Twicaster 小計画: 実装ステップ

## ステップ一覧
1. **HTML/CSSの改修**
   - `src/popup/popup.html`: タブを「ストリーム一覧」「ダウンロード履歴」の2つに集約し、パネルも対応する2つに整理。
   - `src/popup/popup.css`: バッジスタイル（LIVE、VOD、録画中）の定義および不要なタブ関連の微修正。

2. **popup.ts のロジック更新**
   - タブ切り替え（`streams` と `history`）の表示切り替えをシンプル化。
   - ストリーム一覧描画で、全ストリームを最新順（降順）で表示。
   - バッジ表示（LIVEなら赤バッジ、VODなら青バッジ、録画中なら点滅バッジ等）を実装。
   - 詳細表示時・一覧戻り時の表示崩れやクリック不達を修正。

3. **background.ts / content.ts の検証・補強**
   - ポップアップオープン時にも現在開かれているタブからストリーム情報を確実にリフレッシュできる仕組みを確認。

4. **ビルドおよびテスト・型検査**
   - `npm run typecheck` と `npm run build` を実行して正常通過を確認する。
