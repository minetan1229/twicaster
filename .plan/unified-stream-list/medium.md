# Twicaster 中計画: UI設計およびストリーム検出の改修

## 構成変更
1. **HTML構造の簡素化**
   - 不要な `[data-tab="vod"]`, `[data-tab="live"]`, `[data-tab="recording"]` のタブを廃止し、「検出ストリーム」と「履歴」の2タブ（またはシンプル切り替え）に整理。
   - ストリームリスト用のパネルを1つ（`#stream-list-container` / `#streams`）に統合。

2. **ポップアップUIロジック（popup.ts）の修正**
   - `showTab` および `showStreamList` におけるクラス付け替えの不整合を修正。
   - `getFilteredStreams` を撤廃し、検出されたストリームを全件最新順（上に足す順序）で統一リストに表示。
   - 各ストリームアイテムに種別（`LIVE` / `VOD` / 録画中ステータス）のバッジを付与。
   - アイテムタップ時のクリックイベントおよび詳細画面からの戻り時の表示復帰を修正。

3. **ストリーム検出・同期の強化（background.ts / content.ts）**
   - 拡張機能起動時やタブ更新時に開かれている TwitCasting タブのDebuggerアタッチを漏れなく実施。
   - ストリームが検出されたら配列の先頭（上）に追加し、重複時は更新する。
