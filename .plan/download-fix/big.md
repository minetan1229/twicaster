# 大計画 (Big Plan): ダウンロード実行フローのライフサイクル同期と即時フィードバック

## 1. 目的
ユーザーが「ダウンロード」または「全長ダウンロード」を押した際、即座にアニメーション演出・進捗表示を開始し、かつバックグラウンド〜オフスクリーン間のプロセス起動とメッセージングを確実に同期してダウンロードを完遂させる。

## 2. 影響範囲
- `src/shared/types.ts`: `MessageType.OFFSCREEN_READY` 等の定数確認・定義
- `src/offscreen/offscreen.ts`: 起動時の準備完了通知（`OFFSCREEN_READY`）の送信
- `src/background/background.ts`: オフスクリーンドキュメントの存在判定（`hasDocument`）と準備完了待機ロジックの実装
- `src/popup/popup.ts`: クリック即時での進捗バー表示演出（0% / 「準備中...」の表示）

## 3. 品質方針
- 最小設計・段階的コミット（各コミット300行未満）
- ハリボテなしの実装
- 全体ビルド・型チェック・テストのクリア
- PR作成とCI通過の確認
