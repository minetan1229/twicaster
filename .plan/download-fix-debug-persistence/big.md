# Twicaster ダウンロード不具合解消・デバッグモード・状態永続化計画

## 目的
1. 「ダウンロードを準備中...」で処理が止まりダウンロードが開始されない根本原因（オフスクリーン通信のデッドロック、worker/WASMロードエラーハンドリング欠如、ダウンロードAPIエラー検知など）を特定・修正し、確実にダウンロードが進行・完了するようにする。
2. ポップアップやオフスクリーンの状態・通信ログ・エラー詳細を可視化する「デバッグモード（Debug Mode）」をUIおよびバックグラウンドに実装する。
3. ポップアップを閉じても完全リセットされず、入力中の設定（時間指定、画質、ファイル名、選択中ストリーム）およびダウンロード進捗状態・ストリームリストが復元・維持されるようにする。
