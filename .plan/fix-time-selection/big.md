# [Big Plan] 時間指定機能および「現在」ボタン同期の正常化

## 1. 目的
- Twicasterにおいて、VODおよびLIVE配信の両方で時間指定機能が正常に利用できなくなっている問題を完全に解決する。
- 再生中プレイヤーの「現在」時間の取得を確実にし、手動入力した時間指定がストリーム更新通知で勝手にリセットされる不具合を解消する。
- LIVE配信における時間指定ダウンロードがプレイリスト長チェックで拒否される不具合を修正する。

## 2. 計画階層
- [big] 時間指定機能および「現在」ボタン同期の正常化
  - [medium] プレイヤー再生位置のリアルタイム取得APIとフォールバックの整備
  - [medium] ポップアップにおける入力値保護とLIVE配信対応バリデーションの改修
    - [small] content script・background・popup 間のメッセージ連携および入力UI・検証の実装・テスト

## 3. 完了基準
- VOD視聴中に「現在」ボタンを押すと、再生中プレイヤーの秒数が開始時間/終了時間に正しく反映される。
- 時間指定を入力中にバックグラウンドからストリーム情報更新を受信しても、入力中の値が0秒や初期値にリセットされない。
- LIVE配信において「現在」や遡及時間指定を行い、バリデーションエラーなくダウンロードが開始できる。
- `npm run typecheck`, `npm run lint`, `npm run build` がエラーなく通過する。
